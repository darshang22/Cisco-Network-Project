# SR-01: Three-Router Static Routing Lab

## Objective
Configure static routes so that devices on different IP networks can communicate through three routers.

## Tool
Cisco Packet Tracer

## Concepts
- IPv4 addressing and subnetting
- Router interface configuration
- Static routes using `ip route`
- Routing table verification
- End-to-end connectivity testing

## Implementation
1. Assign IP addresses to router interfaces.
2. Configure the required static routes.
3. Check interface status and routing tables.
4. Test connectivity between the relevant networks.

## Verification Commands
```text
show ip interface brief
show ip route
show running-config
ping <destination-IP>
```
